# DYC Culinary Arts Academy

Site vitrine React/Vite pour DYC Culinary Arts Academy, réalisé à partir de la maquette fournie.

## Local

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 4330
npm run build
```

UI : `src/App.jsx` ; styles responsive : `src/styles.css` ; assets : `public/assets`.

La page comprend un hero animé, les ateliers et masterclasses, l’académie, les événements de groupe et un footer. Elle utilise le logo officiel, les photos fournies et des visuels générés. Les animations respectent les préférences de réduction des mouvements.

La navigation et les panneaux sont interactifs. Les demandes sont simulées sans envoi, paiement ou stockage. Le média vidéo reste à fournir.
